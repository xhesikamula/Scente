# Scenté - Perfume Shop Website

**Scenté** – A perfume shop website dedicated to selling perfumes online. Developed a fully responsive website for Scenté, offering a clean, user-friendly interface optimized for desktop, tablet, and phone.

## 🌟 Features

- Fully responsive design for seamless browsing across devices (desktop, tablet, mobile)
- Smooth, modern design powered by Tailwind CSS

## 💻 Technologies Used

- **Tailwind CSS**

## 🚀 Getting Started

To run this project locally:

1. Clone the repository:
2. git clone https://github.com/xhesikamula/Scente.git
   2. Open `index.html` in your browser.

No setup or installation required — just open the HTML file to view the site.

## 🎯 Purpose

This project was created to build a beautiful and functional online perfume shop that provides a smooth, modern shopping experience. The website is optimized for all screen sizes, ensuring a great user experience on any device.
